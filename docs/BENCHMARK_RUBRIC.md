# Weather Command — Comparator Benchmark Rubric

This rubric is frozen before production implementation so release criteria cannot be retrofitted.

Comparator material is non-shipping. Do not copy art, layouts, wording, scenarios, audio, or code.

## 1. Smithsonian Weather Lab
Benchmark dimension: science-learning clarity.

Inspect:
- meteorologist role is instantly understandable;
- air-mass interaction is causally legible;
- learner predicts rather than only reads;
- probable outcomes are presented honestly;
- vocabulary supports reasoning instead of memorization.

Weather Command target:
- preserve role clarity;
- exceed evidence depth with stations/time series/pressure/moisture/wind;
- include confidence and predicted-vs-observed verification.

## 2. NWS/NSSL HotSeat
Benchmark dimension: forecast-workflow authenticity.

Inspect:
- sequential evidence inspection;
- commitment before outcome;
- scenario progression;
- forecast verification;
- feeling of working a forecast desk.

Weather Command target:
- preserve evidence → forecast → commit → observe → verify rhythm;
- remove professional/severe-warning complexity inappropriate for grades 6–8.

## 3. Smithsonian Disaster Detector
Benchmark dimension: middle-school game loop.

Inspect:
- role-based Earth science;
- scientific data changes decisions;
- prediction leads to meaningful action;
- replay/recovery supports systems thinking;
- learning is embedded in play rather than quiz-only.

Weather Command target:
- evidence must change what the player chooses;
- stronger forecast uncertainty/calibration;
- modern responsive/accessibility baseline.

## 4. Mini Metro
Benchmark dimension: commercial systems readability and feel.

Inspect:
- clean information hierarchy;
- immediate input feedback;
- legible changing system state;
- restrained animation/audio;
- coherent visual language;
- accessibility-minded use of color/state.

Weather Command target:
- feel like a polished game, not a school dashboard;
- keep dense evidence readable at a glance;
- use restrained but satisfying transitions and audio.

## Release review dimensions
WC-14 records separate findings for:
1. science/causal integrity;
2. evidence discovery/synthesis;
3. forecast authenticity;
4. uncertainty/confidence;
5. engagement/replay;
6. onboarding/recovery;
7. information hierarchy;
8. visual polish;
9. animation/game feel;
10. audio/feedback;
11. responsive/mobile quality;
12. accessibility;
13. performance.

A major weakness in one dimension cannot be hidden by strength elsewhere.
